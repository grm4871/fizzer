# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's **Report a vulnerability** flow in this repository's Security tab
to send the maintainers a private advisory. Include the affected version,
impact, reproduction steps, and any suggested mitigation. Do not access data
that is not yours or disrupt the hosted service while investigating.

The project is currently in beta and does not promise a fixed response or
embargo timeline. Maintainers will acknowledge actionable reports, coordinate
disclosure when appropriate, and credit reporters who want attribution.

## Supported versions

Security fixes are applied to the latest release. Older beta builds are not
maintained; upgrade before reporting a problem that may already be fixed.
